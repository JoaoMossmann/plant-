# Meu jardim

Uma comunidade para quem cultiva plantas em apartamentos e casas pequenas.

A ideia é reunir um jardim pessoal para acompanhar plantas e cuidados, um espaço para compartilhar experiências e a descoberta de floriculturas e lojas próximas.

Com foco inicial no Vale dos Sinos, o projeto busca aproximar pessoas, conhecimento e negócios locais, com privacidade e segurança desde a concepção.
